Política de Privacidade

Como Seria Pipeline · atualizada em 13/11/2026

Quais dados usamos

O Como Seria Pipeline acessa, com autorização do próprio dono, a conta Google e o canal do YouTube "Como Seria" por meio da YouTube Data API v3. Ele usa apenas os dados necessários para enviar vídeos, definir títulos, descrições, miniaturas e agendamentos, e ler informações básicas do canal.

Como os dados são guardados

O token de acesso fica salvo apenas no computador do dono do canal. Nenhum dado é vendido, compartilhado com terceiros ou enviado a servidores próprios.

Uso de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. O app também está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Ao revogar, o token local deixa de funcionar e pode ser apagado.
